# Contributing

**Creator:** Creator by Bittu Pandit

## Development rules
- Work on feature branches; do not push directly to the default branch for substantial changes.
- Open pull requests with a clear summary, tests, risks, and rollback notes.
- Keep changes small and reviewable.
- Add or update tests for behavior changes.
- Never commit API keys, tokens, credentials, private user data, or local environment files.
- Run formatting, linting, and tests before requesting review.
- Do not claim performance improvements without reproducible benchmark evidence.
- Do not enable autonomous production deployment.

## Reporting issues
Include reproduction steps, expected behavior, actual behavior, environment, logs with secrets removed, and relevant test results.
