# Dataset Source and License Audit

**Creator by Bittu Pandit**

The audit utility reports record counts, exact-text duplicates, source labels, and license identifiers that are not in an explicitly supplied allowlist.

Important: an allowlist match is only a metadata check. It does not establish ownership, compatibility, consent, jurisdictional compliance, or permission for model training. A human must review source terms and retain evidence of permitted use before a corpus enters training.
