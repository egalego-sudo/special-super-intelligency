# Autonomous Project Execution

**SPECIAL SUPER INTELLIGENCY**  
**Creator by Bittu Pandit**

## Objective
Build bounded task planning, dependency tracking, progress reporting, automatic test/fix cycles and approval checkpoints.

## Verification criteria
Acceptance: progress is evidence-based, tasks are reversible where possible, and protected actions require approval.

## Current status
Initial repository automation only.

## Change and release rules
- Keep work in a dedicated, reviewable branch.
- Attach tests and evidence to every implementation change.
- Run unit, integration, regression and security checks as applicable.
- Do not merge, publish a release or deploy production without explicit approval.
