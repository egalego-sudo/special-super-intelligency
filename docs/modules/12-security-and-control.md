# Security and Control

**SPECIAL SUPER INTELLIGENCY**  
**Creator by Bittu Pandit**

## Objective
Implement sandbox isolation, least privilege, secret management, audit logs, threat modeling, permission gates and security tests.

## Verification criteria
Acceptance: threat model, negative tests, access reviews, dependency scanning and documented incident response.

## Current status
Initial controls and CI scanning exist; comprehensive assurance is not complete.

## Change and release rules
- Keep work in a dedicated, reviewable branch.
- Attach tests and evidence to every implementation change.
- Run unit, integration, regression and security checks as applicable.
- Do not merge, publish a release or deploy production without explicit approval.
