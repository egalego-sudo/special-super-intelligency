## Objective
Create safe dataset versioning, training/evaluation pipelines, checkpointing, drift monitoring and regression prevention.

## Verification criteria
Acceptance: reproducible data lineage, validation splits, checkpoint recovery and no silent training on private user data.

## Current status
Toy training/evaluation only.

## Change and release rules
- Keep work in a dedicated, reviewable branch.
- Attach tests and evidence to every implementation change.
- Run unit, integration, regression and security checks as applicable.
- Do not merge, publish a release or deploy production without explicit approval.
